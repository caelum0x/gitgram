# Contributing

## Getting Started
1. Fork the repository.
2. Clone: `git clone https://github.com/yourusername/aitimemachine.git`
3. Install: `npm install`
4. Build: `npm run build`
5. Test: `npm test`

## Development Workflow
- Create a branch for your feature.
- Write tests for new code.
- Ensure linting passes: `npm run lint`
- Submit a PR with description.

## Key Areas for Contribution
- **Testing**: Add unit/integration tests.
- **Features**: Implement roadmap items (see ROADMAP.md).
- **Performance**: Optimize for large codebases.
- **Integrations**: Add MCP tools or AI tool support.
- **Documentation**: Update docs for changes.

## Code of Conduct
Be respectful and collaborative. Focus on solving AI coding challenges.
