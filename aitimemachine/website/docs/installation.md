# Installation

## Prerequisites

- Node.js 18+ and npm
- Git (optional, for advanced features)

## Global Installation

```bash
npm install -g aitimemachine
```

## Development Setup

```bash
git clone https://github.com/yourusername/aitimemachine.git
cd aitimemachine
npm install
npm run build
```

## Verification

```bash
aitm --help
```
